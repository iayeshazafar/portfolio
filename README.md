# Portfolio Website

My personal portfolio website, built with clean HTML5, CSS3, and JavaScript — designed and developed completely from scratch with no frameworks or build tools.

**Live Demo:** [iayeshazafar.vercel.app](https://portfolio-iayeshazafar.vercel.app/)

---

## 🚀 Features & Pages

* **Home:** Overview, about me, technical skills, featured projects, and contact information.
* **Journey** Detailed semester-by-semester academic journey and growth milestones (`journey.html`).
* **Blog:** Writing and documentation on foundational concepts and tech topics I am exploring (`blog.html` & `post.html`).
* **Chatbot  Assistant:** Built-in floating chat widget that responds to common queries about my background and work.

---

## 🛠️ Tech Stack

* **Structure:** HTML5
* **Styling:** Custom CSS
* **Logic:** JavaScript
